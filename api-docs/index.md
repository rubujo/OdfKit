# OdfKit API Reference

OdfKit 是純受控 C#／.NET 的 OpenDocument Format SDK。本站的 API 內容由公開組件與雙語
（英文＋正體中文）XML 文件自動產生。
OdfKit is a pure managed C#/.NET OpenDocument Format SDK. The API content on this site is
generated from the public assemblies and the bilingual (English + Traditional Chinese) XML
documentation.
