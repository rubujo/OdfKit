# Průvodce použitím, shodou, zabezpečením a důkazy

## Rozsah dokumentace API

Referenční dokumentace API se generuje z veřejných sestavení `net10.0` a dokumentace XML. Ručně psaná základní API a veřejná rozšíření se zobrazují na samostatných stránkách. Rozsáhlé, ze schématu generované rozhraní `OdfKit.DOM` nadále spravují základní linie veřejného API pro oba TFM a pokrytí Typed DOM. Souhrny členů jsou dostupné v angličtině a tradiční čínštině; ostatní jazykové vstupy netvrdí, že jsou členy API přeloženy.

## Licence a tvorba pomocí AI

Původní kód a dokumentace OdfKit používají CC0 1.0 Universal. Balíčky, schémata, nástroje a testovací data třetích stran si zachovávají vlastní licence. Veřejný obsah je psán, uspořádán nebo vytvářen pomocí nástrojů AI. Web neposkytuje právní poradenství, SLA ani obchodní odškodnění.

## Hranice zabezpečení a interoperability

U nedůvěryhodných souborů ponechte zapnuté limity prostředků čtečky a balíčku a podle potřeby spusťte ověření nebo sanitaci. Tato opatření snižují riziko, ale nezaručují absolutní bezpečnost před škodlivými dokumenty.
