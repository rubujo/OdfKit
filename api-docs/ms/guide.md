# Penggunaan, pematuhan, keselamatan dan bukti

## Skop dokumentasi API

Rujukan API dijana daripada assembly awam `net10.0` dan dokumentasi XML. API teras yang ditulis secara manual serta sambungan awam dipaparkan sebagai halaman berasingan. Permukaan `OdfKit.DOM` besar yang dijana daripada skema kekal dikawal oleh baseline Public API untuk kedua-dua TFM dan liputan Typed DOM. Ringkasan ahli kini tersedia dalam bahasa Inggeris dan Cina Tradisional; entri Bahasa Melayu ini tidak mendakwa semua ahli API telah diterjemahkan.

## Lesen dan penghasilan AI

Kod asal OdfKit dan dokumentasi asal tapak menggunakan CC0-1.0 Universal. Pakej, skema, alat dan fixture pihak ketiga mengekalkan lesen masing-masing. Kandungan projek awam ditulis, disusun atau dihasilkan dengan alat AI. Tapak ini bukan nasihat undang-undang dan tidak menyediakan SLA atau indemniti komersial. OdfKit bukan projek rasmi atau yang disokong oleh OASIS, The Document Foundation, LibreOffice atau Apache.

## Batas keselamatan dan saling kendali

Kekalkan had sumber reader dan package bagi fail yang tidak dipercayai, serta jalankan pengesahan atau sanitasi yang sesuai. Kawalan ini mengurangkan risiko tetapi tidak menjamin keselamatan mutlak daripada dokumen berniat jahat. Kesahan skema, round-trip atau ujian terhadap satu versi LibreOffice tidak bermaksud hasil yang sama pada tahap piksel dalam semua suite pejabat.

## Keupayaan dan bukti

Tuntutan dipisahkan kepada `PackageFidelity`, `SemanticApiDepth` dan `InteropEvidence`; satu dimensi tidak membuktikan dimensi lain. Keputusan prestasi yang diterbitkan mesti menyatakan commit, runtime, persekitaran dan kaedah yang boleh dihasilkan semula. Belanjawan prestasi masih dalam fasa pengumpulan sampel tetap.
