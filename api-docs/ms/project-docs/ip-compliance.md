# Harta intelek dan pematuhan

> Terjemahan maklumat, bukan nasihat undang-undang. Teks undang-undang asal mengatasi terjemahan.

Dokumen ini membantu usaha wajar pematuhan dan perolehan serta penyumbang. Lihat
[indeks asal usul](https://github.com/rubujo/OdfKit/blob/main/docs/provenance/README.md).

## 1. Model pelesenan gabungan
Kod asal menggunakan CC0-1.0 Universal; kebergantungan, skema OASIS dan fixture mengekalkan lesen serta
OASIS Copyright masing-masing. Pengedaran mesti mematuhi `LICENSE` dan
[THIRD-PARTY-NOTICES.md](https://github.com/rubujo/OdfKit/blob/main/THIRD-PARTY-NOTICES.md), dan keseluruhan
produk tidak boleh didakwa sebagai domain awam.

## 2. Hak dan kandungan AI
Kod, dokumen, contoh dan ujian awam kebanyakannya dihasilkan atau disusun dengan AI. CC0 Affirmer dan
penyumbang mesti mempunyai hak berkenaan; perlindungan berbeza mengikut bidang kuasa. Tiada indemnity komersial.

## 3. Clean-room dan sumber terlarang
Standard awam OASIS/ISO/RFC/W3C, format awam, fixture boleh edar semula dan ujian bebas dibenarkan.
Menyalin LibreOffice C++, Java ODF Toolkit, Apache POI, NPOI, SDK komersial atau binari tertutup yang
dinyahkompil dilarang. JSON Collaboration serasi, bukan port kod sumber.

## 4. Standard dan tanda dagangan
Rujukan deskriptif dibenarkan; pensijilan atau sokongan OASIS, TDF, LibreOffice atau Apache tidak boleh disiratkan.

## 5. Developer Certificate of Origin (DCO)
Penyumbang mesti mengesahkan penciptaan atau hak penyerahan, ketiadaan kod pihak ketiga yang tidak boleh
diedar, pematuhan clean-room dan notis yang dikemas kini. Gunakan `Signed-off-by: Name <email>` jika perlu;
commit juga memerlukan tandatangan GPG.

## 6. Usaha wajar pengguna
Semak lesen dan SBOM, versi `0.x`, had fungsi dan sumber, asal usul serta sokongan. Tiada SLA disediakan.

## 7. Pelaporan keselamatan
Tiada penjejak awam, saluran peribadi atau janji pemprosesan pada masa ini. Jangan terbitkan butiran eksploit
lengkap dan asingkan isu keselamatan daripada lesen atau pelanggaran.
