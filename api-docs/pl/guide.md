# Przewodnik po użyciu, zgodności, bezpieczeństwie i dowodach

## Zakres dokumentacji API

Dokumentacja API jest generowana z publicznych zestawów `net10.0` i dokumentacji XML. Ręcznie napisane podstawowe interfejsy API oraz publiczne rozszerzenia są wyświetlane na osobnych stronach. Duża, generowana ze schematu powierzchnia `OdfKit.DOM` pozostaje zarządzana przez wykazy publicznego API dla obu TFM i pokrycie Typed DOM. Opisy elementów są dostępne w języku angielskim i chińskim tradycyjnym; pozostałe wersje językowe nie deklarują przetłumaczenia elementów API.

## Granice bezpieczeństwa i interoperacyjności

Dla niezaufanych plików pozostaw włączone limity zasobów czytnika i pakietu oraz w razie potrzeby uruchom walidację lub oczyszczanie. Te mechanizmy ograniczają ryzyko, lecz nie gwarantują pełnego bezpieczeństwa przed złośliwymi dokumentami.
