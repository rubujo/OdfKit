> **AI 제작 고지**
> 이 프로젝트의 공개 소스 코드, 문서, 예제, 테스트 및 관련 콘텐츠는 AI 도구를 사용하여 작성, 정리 또는 제작되었습니다.

OdfKit의 독창적인 콘텐츠에는 CC0-1.0 Universal이 적용됩니다. 제3자 콘텐츠에는 해당
라이선스가 그대로 적용됩니다. OdfKit은 OASIS, TDF, LibreOffice 또는 Apache의 공식 프로젝트나
승인받은 프로젝트가 아닙니다. SLA 또는 상업적 면책은 제공되지 않습니다.
