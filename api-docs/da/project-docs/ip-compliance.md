# Immaterielle rettigheder og compliance

> Informativ oversættelse, ikke juridisk rådgivning. Oprindelige juridiske tekster gælder.

For compliance- og indkøbskontrol og bidragydere; se
[proveniensen](https://github.com/rubujo/OdfKit/blob/main/docs/provenance/README.md).

## 1. Sammensat licensmodell
Originalkode bruger CC0-1.0 Universal; afhængigheder, OASIS-skemaer og fixtures bevarer licens og OASIS
Copyright. Distribution skal overholde `LICENSE` og
[THIRD-PARTY-NOTICES.md](https://github.com/rubujo/OdfKit/blob/main/THIRD-PARTY-NOTICES.md), og hele
produktet må ikke betegnes som offentligt domæne.

## 2. Rettigheder og KI-indhold
Offentlig kode, dokumentation, eksempler og tester er hovedsageligt udarbejdet eller organiseret med KI. CC0
Affirmer og bidragydere skal have rettighederne; vern varierer mellem jurisdiksjoner. Ingen kommersiell indemnity.

## 3. Clean-room
Offentlige OASIS/ISO/RFC/W3C-standarder, offentlige formater, redistribuerbare fixtures og uafhængige tester er
tilladt. Kopiering af LibreOffice C++, Java ODF Toolkit, Apache POI, NPOI, kommercielle SDK-er eller
dekompilerede lukkede binære filer er forbudt. JSON Collaboration er kompatibel, ikke en kildekodeport.

## 4. Standarder og varemærker
Beskrivende brug er tilladt; certificering eller støtte fra OASIS, TDF, LibreOffice eller Apache må ikke antydes.

## 5. Developer Certificate of Origin (DCO)
Bidragydere bekræfter ophav eller ret til indsendelse, ingen ulovlig tredjepartskode, clean-room-compliance og
opdaterede meddelelser. Brug `Signed-off-by: Name <email>` efter behov; commits kræver også GPG-signatur.

## 6. Kontroll for brugere
Kontrollér licenser og SBOM, version `0.x`, funktions- og ressourcegrænser, proveniens og støtte. Der tilbydes ingen SLA.

## 7. Sikkerhedsrapportering
Der findes i øjeblikket ingen offentlig tracker, privat kanal eller behandlingsløfte. Offentliggør ikke fuldstændige exploitdetaljer,
og hold sikkerhed atskilt fra licens- og krænkelsessager.

## 8. Relaterede dokumenter
Se [clean-room-indeksen](https://github.com/rubujo/OdfKit/blob/main/docs/provenance/clean-room-source-index.md),
[udvidelsespolitikken](https://github.com/rubujo/OdfKit/blob/main/docs/foreign-extension-policy.md) og
[corpusreglerne](https://github.com/rubujo/OdfKit/blob/main/docs/corpus-manifest.md).
