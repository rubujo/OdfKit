# 使用、準拠性、セキュリティ、根拠ガイド

## API ドキュメントの範囲

API リファレンスは `net10.0` の公開アセンブリと XML ドキュメントから生成されます。手書きのコア API と公開拡張機能は個別のページとして表示されます。大規模なスキーマ生成 `OdfKit.DOM` サーフェスは、引き続きデュアル TFM Public API ベースラインと Typed DOM カバレッジで管理されます。メンバーの概要は英語と繁体字中国語で提供され、他の言語エントリは API メンバーが翻訳済みであるとは主張しません。

## ライセンスと AI 利用

OdfKit の独自コードとサイト文書は CC0 1.0 Universal です。第三者のパッケージ、スキーマ、ツール、fixture には各ライセンスが適用されます。公開コンテンツは AI ツールで作成、整理、または生成されています。このサイトは法的助言ではなく、SLA や商業的な補償は提供しません。

## セキュリティと相互運用性の境界

信頼できないファイルでは reader と package のリソース制限を有効にし、必要に応じて検証またはサニタイズを実行してください。これらの制御はリスクを低減しますが、悪意あるドキュメントからの完全な安全を保証しません。

## 機能と根拠

主張は `PackageFidelity`、`SemanticApiDepth`、`InteropEvidence` に分類され、一つの軸だけで他の軸を証明できません。
