# Security Policy / 安全政策

## No Support or Reporting Channel

OdfKit is provided as-is. This project does not provide security support, a
vulnerability-response commitment, a service-level agreement, a private
reporting channel, or a guaranteed investigation, response, or remediation
timeline.

Do not use GitHub Issues, Pull Requests, Discussions, or other repository
features to report vulnerabilities. Such submissions are outside the project's
support scope and may be closed without investigation or response.

Users are responsible for evaluating risks, validating the software for their
environment, and maintaining any fixes or forks they require. The presence of
this file documents the absence of a vulnerability-reporting program; it is not
an invitation to submit reports.

## 不提供支援或通報管道

OdfKit 依現狀提供。本專案不提供安全支援、漏洞處理承諾、服務等級協議、私密通報管道，
也不保證調查、回覆或修正時程。

請勿使用 GitHub Issues、Pull Requests、Discussions 或其他 repository 功能通報漏洞。
這類提交不在本專案的支援範圍內，可能在未調查或未回覆的情況下直接關閉。

使用者須自行評估風險、驗證軟體是否適合其環境，並自行維護所需的修正或 fork。
本檔案僅用來記錄本專案沒有漏洞通報計畫，不代表邀請任何人提交安全報告。
