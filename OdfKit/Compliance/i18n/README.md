# 在地化例外訊息來源（JSON）

v0.0.1 起，`OdfLocalizer` 例外／診斷字串以本目錄 JSON 為**單一來源真相**。

| 檔案 | 用途 |
|------|------|
| `exceptions.<culture>.json` | 12 語系訊息鍵 → 字串（UTF-8） |
| 產生物 | `../OdfLocalizer.Exceptions.<culture>.cs`（`// <auto-generated />`） |

## 工作流程

1. 編輯或新增鍵：改 JSON，或用  
   `pwsh eng/Add-LocalizerKey.ps1 -Key … -EnMessage … -ZhTwMessage …`  
   （腳手架會寫入 JSON 並重產 C#）。
2. 產生 C#：  
   `pwsh eng/Generate-LocalizerExceptionsFromJson.ps1`
3. 驗證：  
   `pwsh eng/Generate-LocalizerExceptionsFromJson.ps1 -VerifyOnly`  
   `pwsh eng/Test-LocalizerKeyParity.ps1 -FailOnIssues`

**請勿手改** `OdfLocalizer.Exceptions.<culture>.cs`；手改會在 VerifyOnly 失敗。

## 支援語系

`en`、`zh-TW`、`de`、`fr`、`nl`、`nb`、`pt`、`it`、`sk`、`da`、`ms`、`ko`。
